# 💰 TrackIt – Personal Finance Tracker

TrackIt is a full-stack web application built using Django that helps users manage their personal finances efficiently. It allows users to track income, expenses, and savings while providing clear insights through an interactive dashboard.

---

## 🚀 Features

- 🔐 User Authentication (Login/Register)
- ➕ Add, Edit, Delete Transactions (CRUD operations)
- 📊 Dashboard for income, expenses, and savings
- 🎯 Goal Setting for financial targets
- 📅 Track transactions with date and category
- 📈 Real-time financial insights

---

## 🛠️ Tech Stack

- **Backend:** Python, Django  
- **Frontend:** HTML, CSS  
- **Database:** SQLite  
- **Tools:** Git, Postman
